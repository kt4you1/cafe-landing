# 온도 커피 로스터스 랜딩 페이지

가상의 스페셜티 카페 "온도 커피 로스터스"를 소개하는 간단한 한 페이지짜리 랜딩 페이지입니다. 빌드 도구나 외부 라이브러리 없이 HTML과 CSS만으로 만들었습니다.

**배포 주소:** <https://kt4you1.github.io/cafe-landing/>

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 시그니처 메뉴, 이야기, 오시는 길) |
| `style.css` | 스타일. 색상은 `:root` 변수로 관리하며 모바일 화면도 지원 |
| `README.md` | 이 문서 |

## 실행 방법

`index.html`을 브라우저에서 바로 열면 됩니다. 로컬 서버가 필요하면 아래처럼 실행합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 배포

`main` 브랜치에 푸시하면 GitHub Pages로 자동 배포됩니다. 반영에는 1분 안팎이 걸립니다.
